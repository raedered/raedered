## ⭐ Featured Project · Planix

**일정 · 할 일 · 채팅을 한곳에서 관리하는 협업 웹 서비스**

따로 흩어져 있는 일정과 할 일, 대화를 함께 관리할 수 있도록 만든 팀 프로젝트입니다.<br/>
팀원으로 참여해 **날씨 기능, Spring Security · JWT 인증 · 관리자 권한 관리, WebSocket 실시간 채팅**을 담당했습니다.

| 프로젝트 | 내용 |
| :--- | :--- |
| 주요 기능 | 캘린더와 일정 관리, 공유 일정, 친구 관리와 채팅, 커뮤니티 |
| 프로젝트 코드 | [TeampPro / totalproject](https://github.com/TeampPro/totalproject) |
