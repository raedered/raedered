## 🚀 Featured Project

### Planix — 함께 계획하고 소통하는 일정 관리 서비스

개인 일정과 공유 일정, 실시간 채팅, 커뮤니티를 한곳에서 이용할 수 있는 **팀 프로젝트**입니다.

**개발 기간** · 2025.10.29 ~ 2025.12.10

#### 🧑‍💻 제가 맡은 부분

서비스 내 소통 기능과 인증·보안, 날씨 정보 제공 기능을 담당했습니다.

| 담당 기능 | 구현 내용 |
| :--- | :--- |
| 🌤️ 날씨 | 서비스 내 날씨 정보 제공 기능 구현 |
| 💬 실시간 채팅 | 사용자 간 실시간 메시지를 주고받는 채팅 기능 구현 |
| 📝 커뮤니티 | 사용자들이 글을 통해 소통하는 커뮤니티 기능 구현 |
| 🔑 JWT 인증 | JWT 기반 사용자 인증 기능 구현 |
| 🛡️ Spring Security | Spring Boot 애플리케이션에 Spring Security를 적용한 보안 기능 구현 |

#### 🛠️ 프로젝트 기술 구성

- **Backend** · Java, Spring Boot, Spring Security, Spring Data JPA
- **Frontend** · React, JavaScript, Vite
- **Database & Communication** · MariaDB, WebSocket, JWT
